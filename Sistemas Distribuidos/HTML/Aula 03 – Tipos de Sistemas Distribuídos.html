2. Computação de alto desempenho

TipoCaracterísticas
ClusterComputadores de boa qualidade ligados por LAN. Homogêneo (mesmo SO, hardware quase idêntico). Um único nó gerenciador (master) e vários nós de computação.
GradeNós heterogêneos, espalhados entre organizações ou pessoas, em geral em rede de longa distância. Usa organizações virtuais: IDs de usuários agrupados com autorização para usar certos recursos.
NuvemRecursos oferecidos em quatro camadas (abaixo).

Camadas da nuvem

CamadaO que cobreExemplo
HardwareProcessadores, roteadores, energia, refrigeração (escondido do cliente)Datacenters
Infraestrutura (IaaS)Virtualização para alocar servidores e armazenamento virtuaisAmazon EC2
Plataforma (PaaS)Abstrações de alto nível para serviçosMS Azure, Amazon S3
Aplicação (SaaS)As aplicações em siGoogle Apps, YouTube

3. Sistemas de informação distribuídos

As palavras-chave são transação e integração. Muitas aplicações dessa classe se conectam à rede para trocar informações.

Transações e ACID

Uma transação é uma operação atômica. Se algo falhar, ela é abortada (ABORT_TRANSACTION). O exemplo do slide atualiza dois bancos independentes (companhia aérea e hotel) como subtransações aninhadas.

PropriedadeSignificado
AtomicidadeTodas as operações têm sucesso ou todas falham. Em falha, o estado fica inalterado.
ConsistênciaA transação leva a um estado válido. Estados intermediários inválidos podem existir durante a execução.
IsolamentoTransações concorrentes não interferem. Para uma transação T, as outras ocorrem antes ou depois de T.
DurabilidadeDepois do término, os efeitos são permanentes e sobrevivem a falhas.

TP Monitor: quando os dados de uma transação estão em vários servidores, o monitor coordena a execução.

Integração de aplicações (EAI)

Um TP Monitor não basta. Aplicações precisam se comunicar diretamente, via middleware de comunicação:

  • RPC: o cliente chama o método como se fosse local, mas ele pode rodar em outra máquina. Exemplos: Java RMI e gRPC. Um proxy encaminha as requisições ao servidor responsável.
  • MOM (middleware orientado a mensagens).

4. Sistemas pervasivos

Tendência em que os nós são pequenos, móveis e embutidos em sistemas maiores. Ligados à Internet das Coisas (IoT). Os três tipos se sobrepõem.

TipoPontos principais
UbíquosSempre presentes. Requisitos: mudança contextual, autonomia (sem intervenção humana) e inteligência (comportamento emergente, como o flocking).
MóveisSmartphones, tablets, óculos AR/VR. Comunicação sem fio. A localização muda, então a palavra-chave é descoberta. Rotas instáveis levam às redes tolerantes a disrupções. Estudos de rastreamento de celulares mostram que as pessoas tendem a voltar aos mesmos lugares.
SensoresMuitos nós (dezenas a milhares), simples (pouca memória, computação e comunicação) e em geral com bateria. Sentem e atuam no ambiente.

Rede de sensores como sistema distribuído: (a) os dados vão direto ao operador, ou (b) cada sensor processa e armazena dados e envia só respostas a consultas.
